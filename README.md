# sfbot-updates

ช่องทางอัปเดตของ SFBOT (เวอร์ชัน 3.x) - **ปิดให้บริการถาวรแล้ว**

- `sfbot_maintenance.json` - ประกาศปิดบริการ (`maintenance: true`) ยังถูกอ่านโดยโปรแกรมรุ่นเก่า
- `sfbot_version.json` - เวอร์ชันล่าสุดที่เคยเผยแพร่ (3.9.7) เก็บไว้เป็นประวัติ

ไม่มีการเผยแพร่เวอร์ชันใหม่จาก repo นี้อีก และไม่ควรใช้ไฟล์ใน repo นี้เป็นช่องทางอัปเดตของผลิตภัณฑ์อื่น

## หมายเหตุ

ข้อความใน `sfbot_maintenance.json` ถูกแก้ล่าสุดเพื่อแจ้งผู้ใช้เดิมว่าบริการปิดถาวรแล้ว
ถ้าต้องแก้ข้อความอีก ให้แก้ผ่าน commit ปกติ (ไม่ใช่ตัวแก้ไฟล์บนหน้าเว็บ) เพื่อไม่ให้ค่า boolean เสียรูป
